Model settings

Your questions, recent conversation, and relevant course materials go to the model you choose. Remote providers bill your account. Personal requests do not use the instructor’s question allowance.

Weekly keys are encrypted on ATLAS and restored only in this browser for this course. They expire automatically. On a shared computer, use the tab-only option. A ChatGPT or Claude subscription does not include API credit.

Use an OpenAI-compatible local server. Ollama normally uses http://localhost:11434/v1; LM Studio normally uses http://localhost:1234/v1. Load a model and enter its exact ID above.

The browser sends the prepared question directly to your computer. ATLAS still finds the course excerpts. Allow this website in your server’s browser access settings and permit local-network access if your browser asks. Some browser settings may block this connection.

For Ollama, set OLLAMA_ORIGINS to and restart Ollama. For LM Studio, enable CORS (browser access) in server settings. Keep the server restricted to your computer.
